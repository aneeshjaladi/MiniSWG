MiniSWG (Mini Secure Web Gateway)

Asynchronous Forward Proxy, Trie Policy Engine & Admin Console
Candidate / Author: Aneesh Jaladi
Repository: github.com/aneeshjaladi/MiniSWG
Architecture: Zero-Trust Edge / ZIA Inspired

1. Repository & Deployment

GitHub Repository: https://github.com/aneeshjaladi/MiniSWG

Live Demo / Deployed Link: Operates locally as a desktop gateway proxy on http://127.0.0.1:8080. It integrates directly with client operating systems via automated batch scripts and an embedded web admin console at http://127.0.0.1:8080/admin.

2. Technology Stack

  • Backend: Python 3.11+ / 3.13 built entirely on native asyncio. Handles cooperative non-blocking network I/O, raw socket streaming, and HTTP protocol parsing from scratch without third-party web frameworks (using standard library asyncio, socket, urllib.parse, json, and winreg).
  • UI: Embedded Single-Page Application (SPA) served directly from the MiniSWG proxy. Engineered with Vanilla HTML5, responsive CSS3 (dark-mode theme, glassmorphism, Google Fonts Outfit/Inter), and native JavaScript fetch with live polling.
  • Storage & Persistence:
    • Logs: High-fidelity JSON Lines (JSONL) append-only telemetry stream (logs/access.log).
    • Policies: JSON configuration (config/policy.json) compiled into an in-memory reverse-label hierarchical Domain Trie.
    • Database: Zero-dependency file storage + in-memory state for minimal footprint and microsecond lookups.

3. Working Features (Implemented & Validated)

  • HTTP Forwarding: Full parsing of request line and headers, validation, origin connection, and streaming bidirectional response forwarding.
  • HTTPS via CONNECT Tunnel (RFC 9110): Blind bidirectional TCP byte streaming via asyncio.gather with strict domain-level policy gating prior to tunnel establishment.
  • Trie-Based Wildcard Domain Blocking: Reverse-label hierarchical Trie achieving $O(L)$ matching, supporting exact hostnames and wildcard subdomains (e.g. *.casino.com, *.badsite.com).
  • Category Blocking: Maps domains to threat and corporate categories (e.g. Malware, Gambling, Social Media) and blocks requests according to active policy rules.
  • Per-Client Rate Limiting (Token Bucket): Client-IP rate limiting using a lazy-refill monotonic clock algorithm (time.monotonic()) with burst allowance; returns 429 Too Many Requests with Retry-After.
  • Structured Telemetry Logging: Detailed JSON log entries tracking timestamp, client IP, method, host, port, verdict action (allow, block, rate_limited), reason, category, status code, byte metrics, and latency in milliseconds.
  • Zero-Downtime Policy Hot-Reload: Live policy updates without dropping active connections via asynchronous file watcher, POSIX SIGHUP handler, and web admin API triggers.
  • Custom Block Page: Branded HTML block page returned with HTTP 403 Forbidden for blocked web requests, and clean raw 403 termination for HTTPS CONNECT requests.
  • Windows System Proxy Integration: Seamless registry automation (winproxy.py) to dynamically route and restore system-wide browser traffic (Edge, Chrome, Brave) to MiniSWG with 1 click.
  • 1-Click Launchers: Start_MiniSWG.bat and Stop_MiniSWG.bat providing immediate execution and clean restoration for end-users.
  • Integrated Benchmark Harness: Built-in multi-concurrency benchmarking suite (bench/run_bench.py) measuring throughput and tail latencies.

* Note: Unimplemented enterprise features (such as JWT user authentication or SSL/TLS MITM decryption) have been omitted.

4. Web Admin Dashboard Capabilities

Accessible at http://127.0.0.1:8080/admin, the dashboard enables non-technical and security admins to:

  • Live Telemetry & Activity Feed: Auto-refreshing feed displaying client IP, request method, destination host, action badge (allow / block / rate_limited), category, status, and latency.
  • System Counters: Instant visibility into uptime, total requests processed, and threat blocks enforced.
  • 1-Click Windows Proxy Switch: Global header control to route all workstation traffic through the gateway or restore direct connection.
  • Visual Category Policy Management: One-click toggles to instantly enable or disable blocking for Malware, Gambling, and Social Media.
  • Custom Rules & Allowlist Creator: Web form to add new domain rules or allowlist entries without manual JSON editing.
  • Interactive Domain Inspector: Real-time domain tester returning immediate policy verdicts, matched rules, and contextual syntax hints.
  • Rate Limit & Policy Editor: Configuration panel to adjust requests-per-minute and burst thresholds with instant hot-reload.
